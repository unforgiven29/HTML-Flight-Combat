DESCRIPTION: Parameter registry for the F-16 vs MiG-29 air combat sim sensor

             radar+IRST fusion; 30-38 conventional pulse radar; 39-56 realism

             reliability). Types: number, boolean, string, Enum, Vec2, Vec3,
             Array, Curve (lookup table). Units noted in each description.
