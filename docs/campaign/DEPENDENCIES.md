## Contract checks

- State keys with more than one creator: none (the first in load order is the owner; others only create it if it is missing).
- Every daily hook runs inside try/catch (store.js times each one and reports repeated failures).
- Every module writes only its own state key and changes others only through the shared hooks or documented, bounded effects.
