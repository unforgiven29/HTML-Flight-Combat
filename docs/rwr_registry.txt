================================================================================
          VIPER SORTIE RADAR WARNING RECEIVER (RWR) REALISM PARAMETER REGISTRY
================================================================================
VERSION: 1.0.0
CLASSIFICATION: GAME DESIGN / ARCHITECTURAL SPECIFICATION REFERENCE
DESCRIPTION: Standalone parameter list for a realistic RWR/ESM warning system
             on the F-16 and MiG-29: antennas, receiver, pulse measurement,
             direction finding, deinterleaving, emitter library, threat
             states, range/lethality estimation, missile warning, display and
             audio, countermeasure cueing, environment, and faults. Companion
             to the radar/IRST sensor registry; this file replaces its RWR
             sections 12 and 48 for detail. Types: number, boolean,
             string, Enum, Vec2, Vec3, Array, Curve (lookup table).
================================================================================
